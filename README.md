# Jabali_Technical_Documentation
Jabali Technical Documentation
This repository contains the technical documentation for **Rejesha Green**, a digital forest-management platform designed and created by Jabali.
Rejesha Green is a mobile platform that helps Community Forest Associations(CFA), Community Forest Associations(CFA)members, Kenya Forest Services (KFS) officials, forest rangers, and conservation organizations manage forest-related activities through a centralized digital system.
## What the platform supports
CFA member registration
Forest-resource permit requests
Illegal-activity reporting
Conservation planning
Tree-restoration monitoring
SMS and USSD services
Mobile money payments through M-Pesa
Notifications and reminders
Role-based access control
